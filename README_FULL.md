# AI 伴读助手 - 完整开发文档

基于 Next.js + React + Tailwind CSS + Supabase + DeepSeek API 的智能文档阅读平台，支持百万字级文档阅读、AI 伴读、笔记管理和思维导图生成。

## 🔧 环境配置

### 1. 环境变量
复制 `.env.example` 为 `.env.local`：

```env
# Supabase 配置
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

# DeepSeek API 配置
DEEPSEEK_API_KEY=your-deepseek-api-key

# 应用配置
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 2. 获取 API 密钥

#### Supabase
1. 访问 [Supabase](https://supabase.com)
2. 创建新项目
3. 在 Settings > API 中获取 URL 和 Anon Key

#### DeepSeek
1. 访问 [DeepSeek 平台](https://platform.deepseek.com)
2. 使用手机号 15922233923 登录
3. 在 API Keys 页面创建新密钥

### 3. 数据库初始化
运行提供的 SQL 脚本：
1. 创建 users、documents、notes 表
2. 启用 Row Level Security
3. 创建 Storage bucket 和策略
